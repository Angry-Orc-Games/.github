# Angry Orc Games

Independent tabletop RPG publisher. We make the **Pivot** game system, 5e-compatible adventure modules, and the digital tools that run them at the table.

🌐 [angryorcgames.com](https://www.angryorcgames.com/)

## What we build here

| Project | What it is |
|---|---|
| [**pivot-foundry**](https://github.com/Angry-Orc-Games/pivot-foundry) | The official [Foundry Virtual Tabletop](https://foundryvtt.com/) system for the Pivot Game System. It's the core rules engine for Pivot Fantasy, Pivot Sci-Fi, and future settings. |
| Pivot Fantasy tools | Foundry modules and companions for Pivot Fantasy, like the Monster Builder and the character generator. |

## Our games

- **Pivot Game System**: our own tabletop RPG system, with Pivot Fantasy first and more settings planned.
- **5e-compatible adventure modules**: ready-to-run adventures for fifth-edition games.

Find our books and PDFs at [angryorcgames.com](https://www.angryorcgames.com/).
